# Desired Client write-in answers

The guided questions now provide an optional, single-line "Other: write your own answer" field for timing, first contact, client goals, client concerns, firm reasons, fee compared with effort, delivery conditions, current capacity, delivery limits, reputation aim, and supporting evidence. The selected work and client role retain their pre-existing Other fields.

A custom answer can satisfy a required question. Selecting a preset answer clears a competing radio write-in. Existing saved drafts without the optional write-ins object remain valid. Each answer is limited to 180 characters, asks for general information without names or confidential details, and is preserved in the review, brief, copy, Markdown, and print views. Gemini receives the answer as labelled, untrusted user text; source validation allows the matching answer reference.

Verification: 46 Desired Client unit tests; 320px and 768px custom-only browser journeys including reload and resume. A synthetic custom-answer request reached the live Gemini adapter in local testing; the local preview's end-to-end AI route still needs its Redis preview configuration. No production settings were changed.
