# GTA prospect batch 006

This is a read-only research batch of 25 public, first-party GTA firm records. Every record is a **candidate**, not an accepted prospect or a delivery instruction.

## What this batch establishes

- A public firm-controlled roster or team page identifies 3–10 observed lawyer roles, subject to the recorded qualifier.
- A public firm-controlled page identifies a GTA office location.
- The record was reconciled against the PR #231 baseline and batches 001–005 using canonical domain and firm name. No exact match was found.

## Boundaries

This batch did not use LSO automation, bot bypass, forms, chats, contact actions, CRM, imports, paid data, or private data. It does not authorize outreach, enrolment, data transfer, a profile update, or any claim about a firm’s performance.

## Interpretation rules

- `exact` means the displayed lawyer roster has a bounded set of lawyer roles, with non-lawyer roles separately labelled.
- `at_least` means the public page supports the displayed minimum but leaves a material roster-boundary or role-classification uncertainty; those records require a fresh first-party review before acceptance.
- `legacy_rows` is deliberately `unknown_no_stable_crosswalk`. The older data cannot be matched safely without a durable record identifier; a no-exact-match result is not proof that a legacy entity is absent.
- Names, offices, practice labels, and counts are public-page observations as of 2026-09-07, not durable identity or quality assertions.

Load only these candidate records into the local review surface, filter by count band and city, and retain each source URL and uncertainty.
