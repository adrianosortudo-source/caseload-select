Three options for each ACTS phase

Selected family: A3 Authority Column, C3 Channel Intake, T3 Focus Frame, and Screen A Ranked Intake Gate. This route is more distinctive than the sealed set while staying premium and legible at hero size.

Phase A
Authority
Option 1A

Verified Counsel Seal

Shield, citation bars, and a terminal square. Reads as trust, proof, and professional authority without feeling like a stock security icon.

Option 2A

Evidence Ledger

Publication and review signals arranged like a legal record. Strong for the "content, reviews, brand trust" meaning of Authority.

Option 3A

Authority Column

Architectural, calm, and institutional. The least literal option, useful if the brand wants a more editorial signal.

Phase C
Capture
Option 1C

Local Signal Field

Search radius plus a captured inbound path. It suggests visibility infrastructure rather than generic lead generation.

Option 2C

Index Aperture

Pages, map grid, and entry point. A more SEO-native icon for organic visibility and local findability.

Option 3C

Channel Intake

Signals flowing into one contact point. A direct metaphor for capturing demand across search, GBP, and local channels.

Phase T
Target
Option 1T

Matter Precision

A target that feels calibrated, not militarized. The selected quadrant makes the ad-spend decision visible.

Option 2T

Bid Path

Spend narrows toward the matter type worth buying. Useful if Target should read more like paid media operations.

Option 3T

Focus Frame

Minimal corner brackets and a center proof point. Premium, quiet, and very legible at small sizes.

Phase S
Screen
Option 1S

Ranked Intake Gate

Questions flow through a gate and exit as a ranked case. Strongest tie to CaseLoad Screen without the old funnel look.

Option 2S

Priority Queue

Three inquiries resolve into one priority decision. Best if the icon must communicate routing and banding clearly.

Option 3S

Scored Brief

A document, score bar, and terminal square. More product-specific, good for Screen demo surfaces and reports.
