# GTA prospect batch pipeline

This is the governed, reusable artifact step between public research and a separately authorized import. It does not crawl sites, query Supabase, write CRM records, create contacts, submit forms, send outreach, or merge firm identities.

## Inputs and gates

Create one review file using `gta-prospect-batch-review.v1`. Its policy must declare `requiredRosterProvenance: "first_party"` and the selected `targetCountBands`. Each candidate needs a stable `recordId`, firm/domain/city, first-party roster evidence, count qualifier, and one reviewer decision. Every decision records independent static-baseline and live-baseline identity outcomes; every candidate must have exactly one `import`, `exclude`, or `hold` disposition with a written basis.

Only `import` decisions become manifest records. They require an exact integer roster count inside the declared target bands, an explicit `provisional_new` or `update_existing` reconciliation status, and a `no_match` result from the live identity review. A duplicate canonical domain within the proposed import fails the run. The script does not decide identity matches; a live match or unresolved result must remain `hold` or `exclude` until reviewed.

## Commands

```powershell
node scripts/prepare-gta-prospect-batch-import.mjs --review docs/research/gta-prospect-batch-013/review.json --output-dir docs/reconciliation/gta-prospect-batch-013
node scripts/prepare-gta-prospect-batch-import.mjs --review docs/research/gta-prospect-batch-013/review.json --output-dir docs/reconciliation/gta-prospect-batch-013 --check
npm run prospects:test-batch-pipeline
```

The first command writes `reviewed-resolution.json` and `reviewed-import-manifest.json`. The second proves those committed artifacts are current. Generation is not an import: applying a manifest requires a fresh live, read-only preflight and separate operator authorization.

Batch 012 remains on its existing `prospects:prepare-batch-012-import` command and date-stamped artifacts. Its historical source hash and production receipt are not regenerated by this generic pipeline.
